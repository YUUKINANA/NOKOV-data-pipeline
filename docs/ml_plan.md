# 机器学习路线规划

本文记录本项目后续使用机器学习的建议方向。当前阶段不建议直接训练“大模型控制机器人”，而是先围绕已跑通的动捕复现链路做小而稳的模型。

## 1. 当前基础

已经具备：

- 24点手部动捕数据采集；
- 结构化保存与处理；
- 几何算法估计 6维手部控制量；
- REVO2 离线回放和实时复现；
- 机械安全输出层。

因此最适合的第一类机器学习任务是：

```text
24点手部数据 / 几何特征 -> 更稳定、更自然的 6维 REVO2 控制量
```

## 2. 为什么不直接端到端控制

从相机图像或动捕点直接输出电机指令虽然可行，但早期风险较高：

- 数据量不足；
- 真实硬件调试成本高；
- 出错可能导致机械冲击；
- 不容易解释给导师和同学；
- 很难定位问题来自感知、模型还是执行器。

因此建议采用分层路线：

```text
动捕/视觉数据
  -> 状态估计
  -> 几何/规则基线
  -> 机器学习修正
  -> 机械安全输出层
  -> 机器人执行
```

## 3. 第一阶段：个体化映射模型

目标：

```text
让 REVO2 更稳定、更准确地复现人的手部动作
```

输入候选：

- 手掌坐标系下的 24点坐标；
- 每根手指骨段向量；
- 关节夹角；
- 指尖到掌心距离；
- 指尖到手腕距离；
- 相邻指尖距离；
- 上一帧 6维控制量；
- 当前速度或变化量。

输出：

```text
[拇指弯曲, 拇指辅助/侧摆, 食指, 中指, 无名指, 小指]
```

推荐从以下模型开始：

- Ridge Regression；
- Random Forest；
- 小型 MLP；
- 几何算法输出 + ML 修正量。

最推荐：

```text
最终输出 = 几何算法输出 + 机器学习修正量
```

这样几何算法负责基本方向，机器学习只修正非线性、个体差异和 REVO2 响应差异。

## 4. 第二阶段：episode 数据集

后续要将每次示教都保存为 episode：

```text
episode_xxxx/
├─ metadata.json
├─ mocap_points.csv.gz
├─ hand_features.csv
├─ controls_6d.csv
├─ revo2_commands.csv
├─ robot_state.csv        # 后续接机械臂时加入
├─ camera/                # 后续接视觉时加入
└─ notes.md
```

基础动作建议：

- 张开；
- 自然半握；
- 最大可接受抓握；
- 重复张开-闭合；
- 捏合；
- 单指弯曲；
- 拇指对掌；
- 抓取简单物体。

## 5. 第三阶段：机械臂与视觉

当机械臂加入后，数据流扩展为：

```text
相机图像 + 机械臂状态 + 灵巧手状态 + 动捕/示教动作
  -> 策略模型
  -> 机械臂轨迹 + 灵巧手动作
```

此时可考虑：

- 行为克隆；
- Diffusion Policy；
- ACT；
- LeRobot 数据格式；
- 强化学习或仿真训练。

但这些都应建立在稳定的采集、标注和安全执行层之上。

## 6. 近期任务

1. 稳定实时复现参数。
2. 做手部开合、捏合、单指动作标定。
3. 统一 episode 数据格式。
4. 编写特征提取脚本。
5. 训练第一版 6维映射小模型。
6. 与几何算法对比稳定性、延迟和误差。
